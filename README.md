# kicad-packages

KiCad Plugin and Content Manager (PCM) repository for inoson packages.

Add this URL in KiCad under *Plugin and Content Manager → Manage…*:

```
https://raw.githubusercontent.com/inoson/kicad-packages/main/repository.json
```

## Layout

- `packages/<identifier>/metadata.json`: package metadata with all published
  versions ([KiCad PCM schema](https://go.kicad.org/pcm/schemas/v1))
- `packages/<identifier>/icon.png`: 64x64 package icon
- `packages.json`, `resources.zip`, `repository.json`: generated by
  `build_repository.py`, never edit by hand

## Publishing a version

1. Upload the package zip as a GitHub release asset in the plugin repository
2. Add the version entry (download URL, SHA-256, sizes) at the top of `versions` in the package's `metadata.json`. Plugin repositories may automate this (e.g. `make_inoson_release.py` in `inoson/InteractiveHtmlBom`)
3. Run `python build_repository.py --validate` (validation needs `jsonschema`) and commit everything
